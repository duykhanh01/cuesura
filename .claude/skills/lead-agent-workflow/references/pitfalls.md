# Remaining lessons

Only lessons not already encoded in workflow, helper or tool cards belong here. Prefer fixing the
cause, a behavior check or a reviewer rule first; remove an entry once covered elsewhere.

- Search before creating an authorized follow-up issue; duplicate flake issues split the evidence.
- Another person's branches and PRs remain theirs. Port authorized work with source links and
  credit rather than rewriting their history.
- Closing or replacing an issue can leave a source spec stale. Update the actual source within
  scope rather than leaving contradictory acceptance criteria for the next reviewer.
- A recurring flake deserves a bounded investigation with before/after evidence and intact tests,
  rather than permanent rerun folklore.
